00

The idea

A website is just files.

Your browser reads files and turns them into the page you see. For a basic website, you normally start with three:

<>index.htmlThe content and structure
#style.cssColors, spacing, layout
{ }script.jsClicks and behavior
For now: focus on index.html. You can make a real webpage with that one file.
01

The building block

HTML is made of tags.

A tag tells the browser what something is. Most have an opening tag, some content, and a closing tag.

Tap any part to see what it means.

HTML
<h1>My first website</h1>
<p>I finally understand this.</p>
<button>Click me</button>
Translation

Make one main heading, one paragraph, then one button. That's it.

02

Content

Put real things on the page.

These are the tags you'll use constantly. You do not need to memorize 100 tags — start with the useful ones.

<h1>

Your main page heading. Usually use one main h1 per page.

HTML
<h1>Plexium</h1>
<p>A project I'm building while I learn.</p>
<a href="https://github.com">Open GitHub</a>
href="https://github.com"
This is an attribute.

Attributes add extra information to a tag. Here, href tells the link where to go.

03

Structure

Things can live inside other things.

This is called nesting. Think folders inside folders. Indentation lets your eyes see who belongs to who.

div.card
h2MacBook Pro
pA laptop card.
buttonView
HTML
<div class="card">
  <h2>MacBook Pro</h2>
  <p>A laptop card.</p>
  <button>View</button>
</div>
Shortcut: when AI gives you a huge file, look for the outer containers first. Header → main → section → card. The code gets way less scary.
04

Names

Classes give elements a reusable name.

CSS and JavaScript need a way to find things. A class is normally reusable; an id normally points to one unique element.

Reusable

class

class="card"

Use it on 1, 5, or 50 cards.

CSS finds it with .card
Unique

id

id="search"

Use it for one specific search box.

CSS finds it with #search
HTML
<div class="card">First card</div>
<div class="card">Second card</div>

<button id="saveButton">Save</button>
05

Input

Let the visitor type and choose.

Forms hold inputs. The browser already gives you text boxes, checkboxes, sliders, date pickers and more.

HTML
<form>
  <label>
    Project name
    <input type="text" placeholder="My website">
  </label>

  <button type="submit">Create</button>
</form>
06

Make it look good

CSS styles your HTML.

HTML says “this is a card.” CSS says “make that card white, rounded, and spaced nicely.” Connect style.css inside the page's <head>.

HTML
<link rel="stylesheet" href="style.css">

<div class="card">Hello</div>
CSS
.card {
  padding: 24px;
  background: white;
  border-radius: 20px;
}
margin — outside
border
padding — inside
content
Remember this one: padding is space inside the element. margin is space outside it.
07

Make it respond

JavaScript adds behavior.

You don't need JavaScript to learn HTML. But this tiny example explains what AI is doing when it makes a button actually work.

1Findthe button
→
2Listenfor a click
→
3Changethe page
JavaScript
const button = document.querySelector("#helloButton");

button.addEventListener("click", () => {
  button.textContent = "It worked ✨";
});
08

When it breaks

Errors are clues, not doom.

Press F12 in your browser. The two tabs beginners should care about first are Elements and Console.

⌖

Elements

Click anything on the page. See its HTML and CSS. Change styles live without saving.

›_

Console

See JavaScript errors and print values with console.log().

Better AI debugging prompt

Before changing my code, explain the error in beginner-friendly terms. Tell me the exact file and line causing it, why it happens, and then make the smallest possible fix. Do not rewrite unrelated code.
